## 3. 進行中の作業：住人 1,500 人の顔と名簿

ユーザーの方針（決定済み）:
- 1,500 人の住人は、名前・顔・年齢・性別・家族・部屋・性格を固定する（名簿にする）。
- 誰が避難・籠城・死亡・略奪者になるかは、これまでどおり毎回変わる。
- 名前は顔の雰囲気と世代から付ける（例：80 代なら「キヨ」「正雄」、子どもなら「陽菜」「蓮」）。名字は家族で共通にし、町全体では偏らせない。
- 性格は顔と無関係に割り振る（見た目で決めつけない）。

進み具合:
- ユーザーが 2×2 のシート（4 人ずつ）を約 350 枚作っている。既存の顔 104 人と合わせて約 1,500 人分。
- 受け取り済みは 48 枚（192 人）。`assets/residents/r0001.jpg`〜`r0192.jpg` が 512×512 の JPEG。
- 記録は `data/resident_faces.json` にある。中身は `[{id, sex(m/f), age(推定), look(見た目メモ), src}]`。
- 切り出しには `ci/tools/cut_sheets.py <batch.json>` を使う。batch は `[[アップロード画像パス, [[sex, age, look] ×4（左上→右上→左下→右下）]], ...]`。白い区切り線があれば自動で検出し、無ければ中央で分ける。記録は既存の `resident_faces.json` に追記し、ID は続き番号になる。
- これまでの内訳は子どもが少ない（192 人中およそ 20 人）。子どものいる家族を組むには子どもが約 200 人要るので、多めに作ってもらうよう伝えてある。

残りの作業:
1. 残り約 300 枚を受け取って切り出す。使用量の消費が大きいので、ユーザーに次のどちらかを頼むのがよい。
   - 各シートの 4 人の性別・年代をテキストで添えてもらう。
   - zip で渡してもらう。
2. 全部そろったら、名簿 `data/residents.json` を作る。
   - 年代と性別から家族を組み、790 世帯の部屋（`residents.gd` の AREAS と `District.homes_in`）に割り当てる。
   - 名前・性格・短い身の上を付ける。
   - ユーザーが確認できる一覧（Artifact）を出す。
3. `residents.gd` の `who()` を、seed から計算する方式から名簿を読む方式に切り替える。顔は `portraits.gd` で `assets/residents/<id>.jpg` を使う。テストを直す。
4. その後に IPA をビルドする。
   - v149.33 のワークフローをもとに v149.35 用を作り、パッチの後に画像コピーの手順を足す。
   - 成果物（artifact）のダウンロード URL をユーザーに渡す。
