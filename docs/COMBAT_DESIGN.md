# 戦闘の設計（v149.33〜）

> **正の仕様はユーザーの「戦闘システム・成長・報酬 統合実装仕様書」（2026-11-20）。** その要点と、実装の進み具合をこのファイルの冒頭にまとめる。
> 下の「旧設計メモ」は議論の経緯として残すが、仕様書と食い違う所は仕様書に従う。

## 仕様書の要点（旧メモとの違い）

- 入力中は時間が止まり、行動ごとに**計算した秒数**だけ進む（固定値ではなく、身体能力・武器の重さ・疲労・負傷・地形・障害物・移動距離から）。その間、感染者とNPCも同じ時間軸で動く。複数行動は、途中で状況が大きく変わったら残りを中断して再判断させる。
- LLM は**解釈と描写だけ**。解釈：行動の種類・武器や道具・対象・部位・移動方向・目的・順序。曖昧なら勝手に補わず確認する。描写：ルールエンジンが確定した結果だけを文章にする（命中・負傷・死亡を足さない）。
- 成功率は数値を出さず「狙いやすい／難しい／かなり難しい」。物理的に不可能な行動は乱数でも成功しない。
- 武器の特性：重量・長さ・攻撃範囲・扱いやすさ・損傷能力・耐久性・疲労への影響・狭所での制限・攻撃後の隙。改造品が元より優れるとは限らない。
- 部位：頭（命中＝必ず倒せるわけではない）・脚（速度低下・転倒・歩行不能）・腕（つかむ力・攻撃）・胴（構造と損傷の程度で判定）。
- プレイヤーの負傷：打撲・裂傷・骨折・出血・噛み傷・感染・疲労。戦闘後も続き、移動・作業・暮らしに影響。防具は材質・厚さ・覆う範囲で決まる。**切断は実装しない。**
- **仲間NPCは完全自律**（性格・経験・能力・恐怖心・負傷で判断し、逃走・回避・防御・隠れる・救助要請）。安全な場所でのランダム死亡はなし、危険は段階的に描写し介入の機会を作る。危険な指示・警告の無視・救助失敗による死亡は認める。
- 熟練度は打撃・刃物・身のこなしの3系統、**Lv.1〜100**（最大でも超人にはならない）。経験値は行動内容・難易度・新規性・現在の熟練度から（撃破数だけで決めない）。安全な場所での繰り返し稼ぎは制限。
- **技術の習得**（狙いの安定化・距離感・受け流し・冷静な対処・武器操作の効率化・疲労を抑える動作）。徐々に上達し、未習得でも自由文で試せる。
- **観察能力**：経験で描写が細かくなる（初心者「近づいてくる」→熟練者「右脚が鈍く、方向転換は難しそう。ただし腕を伸ばせば届く距離」）。見えないものは出さない。
- **戦利品は自動生成しない**：感染者ごとの生前の所持品（財布・鍵・バッグ・工具・医薬品・メモ・携帯）を、死体を調べて回収。新しい場所や情報につながることも。
- **地域の安全度**は感染者の分布・移動・騒音・人の活動・封鎖・バリケードで変わる（「何体倒せば何日安全」の固定にはしない）。周囲からの流入は残す。
- 籠城戦：扉・窓・壁の耐久、バリケード、数と位置、騒音による追加接近、NPCの防衛・避難、拠点内の移動、失敗時の撤退。盛り上げのために感染者を不自然に増やさない。
- 戦闘終了時に短い結果表示（撃破数・経過時間・負傷・武器の損耗・熟練度経験値・技術習得・確認済みの戦利品・周辺への影響）。経験値は数値で出してよい。
- 実績・称号（初撃破・10体・100体・拠点防衛・群れから生還・30日無殺傷・共闘・重傷から生還）。能力の強化はしない。
- 結末に戦闘履歴（撃破数・戦闘回数・負傷・武器・防衛回数・共闘・無殺傷・熟練度）を反映。

### 段階1の作り（v149.33）
- `encounter.zombies = [{id, dist, state, hurt{head,arms,legs,torso}, kind}]`。近い順に最大6体を個別に持ち、残りは数だけ（`Walkers.count`）。古い保存データは初回に数から作る。
- `Combat.sync`：数と個体を合わせる（倒された分は一番手前から消える＝重複撃破なし）。気づかれた（`near`）ら先頭は2m以内。
- `Combat.seconds`：行動ごとの基本秒数×疲労×負傷×地形。`Combat.tick`：気づいた個体だけ、種類ごとの速さ（新しい1.3m/s・傷んだ0.8m/s・這う0.3m/s）で近づき、腕の届く0.6mで止まる（つかみかかる判定はまだ walkers.gd）。
- 画面上部の戦闘状況欄：数（暗いと「何人かいる」）・一番近い距離（暗いと「はっきりしない」）・気づかれているか・手持ち・場所・体・狙える部位の目安。
- 勝ち負けの判定は、まだ今までの `Walkers.resolve`（段階2で置き換える）。

# 旧設計メモ（議論の経緯）

方針：**戦いは楽しい、上手くなれる、ご褒美もある。でも噛まれたら終わりで、数と音には常に気をつける。**
リアルさは緊張を生むための味付けとして使い、ゲームとしての面白さを優先する。

---

## 1. いまの仕組み（出発点）

- 遭遇は `walkers.gd` の `w.encounter = {place, count, near, since, from}`。
- 行動は5種類：隠れる・逃げる・物を投げる・戦う・様子を見る（`Walkers.intent`）。
- 戦う時の成功率は `30 + 武器 + 15×味方 − 心の動揺`（5〜90%）。1回の入力で1体倒すか、外すか、つかまれる。
- 武器は持ち物の木材（+15）か部品（+20）で代用している（`weapon_bonus`）。
- つかまれた時に噛まれる確率は `8 + 12×(近くの数−1)` で、`protection` の割合だけ下がる。
- 倒した数は `w.killed` に数えている。

この遭遇を作り直すのではなく、**1ステップ目として残したまま中身を厚くする**。

---

## 2. 戦闘の流れ：入力ごとに数秒進む

スマホで日本語を打つのは遅いので、本当のリアルタイムにはしない。

- 打っている間、時間は止まっている。送信した瞬間に、その行動の分だけ時間が進む。
- 行動ごとに、かかる秒数が違う。長い行動ほど相手が近づく。

| 行動 | 秒数の目安 |
|---|---|
| 振る・突く・蹴る | 2秒 |
| 押し返す・扉を閉める | 2秒 |
| 数歩下がる・横に回る | 3秒 |
| 走って逃げる | 4秒 |
| 周りの物を探す・拾う | 5〜6秒 |
| 様子を見る | 2秒 |

- ゾンビは1秒に約1mずつ近づく。0mになると「つかみかかる」判定が起きる。
- 画面の上に**状況欄**を常に出す（例）。

```
距離 2m ・ 正面に1体（右脚を引きずっている） ・ 後ろの通路から足音
右手：鉄パイプ（傷あり） ・ 体：疲れてきた ・ 場所：狭い廊下
頭：まだ難しい ／ 脚：狙える ／ 押し返す：できる
```

## 3. 遭遇の状態（新しく持つデータ）

`w.encounter` を拡張する。保存データとの互換のため、新しいキーはすべて `get(…, 既定値)` で読む。

```
encounter = {
  place, since, from,                       # いまと同じ
  zombies: [                                # 1体ずつ
    {id, dist: 3.0, state: "standing",      # standing / downed / crawling / pinned / dead
     hurt: {head: 0, legs: 0, arms: 0},     # 部位ごとの傷
     kind: "fresh"}                         # fresh（新しい・速い）/ old（傷んで遅い）/ armored（ヘルメット等）
  ],
  terrain: "street",                        # street / corridor / doorway / stairs / room / fence
  noise: 0,                                 # この戦いで出した音
  beat: 0,                                  # 何手目か
}
```

- 遠くにいる群れの残りは `count` として数だけ持ち、音が大きいと近づいてくる。
- いまの `count / near` は、この配列から計算して返す（古い保存データもそのまま動く）。

## 4. スキル：使うほど上がる

3種類だけにする。すべて0〜100で、最初は低い。

| スキル | 上がる時 | 効くところ |
|---|---|---|
| 打撃 | バット・パイプ・バールで当てた時 | 打撃武器の命中、頭への届きやすさ |
| 刃物 | 包丁・槍で当てた時 | 刃物の命中、刺さって抜けない確率が下がる |
| 身のこなし | 逃げる・避ける・押し返すに成功した時 | 逃げる・つかまれた時に振りほどく |

- 1回成功すると +3。上がるほど伸びが遅くなる（`+3 × (1 − 今の値/120)`）。
- 失敗しても少しだけ上がる（+1）。怖い思いも経験になる。
- 保存先は `s.combat = {skills: {strike, blade, agility}, kills_by: {…}, worst_wound: …}`。
  **`s.inventory` には足さない**（古い保存データの検証が `s.inventory` のキーと比べているため）。

**過去の経験**：世界ごとに一つだけ、主人公の過去を決めて少し上乗せする（ランダム）。

| 過去 | 上乗せ |
|---|---|
| 学生時代は野球部だった | 打撃 +15 |
| 料理が趣味で、包丁には慣れている | 刃物 +15 |
| 運動は苦手だが、逃げ足だけは速い | 身のこなし +15 |
| 武道を少しかじっていた | 打撃 +8・身のこなし +8 |
| 特に何もない | なし（そのかわり心が少し強い） |

序盤の文章で一度だけ触れる（例：「玄関の傘立てに、高校の時に使っていた金属バットが立てかけてある」）。

## 5. 武器

武器ごとに強みと弱みを持たせ、場面によって選ぶ意味を出す。

| 武器 | 種類 | 命中 | 頭への効き | 間合い | 音 | 重さ | 特徴 |
|---|---|---|---|---|---|---|---|
| 素手・蹴り | — | ふつう | ほぼ無理 | 0m | 小 | — | 押し返す・転ばせるのは可能 |
| 包丁 | 刃物 | 高 | 刺されば一撃 | 0.5m | 小 | 軽 | 骨に刺さって抜けないことがある |
| 金属バット | 打撃 | 高 | 低（何度か要る） | 1m | 大 | 中 | 脚を払いやすい |
| 鉄パイプ | 打撃 | 中 | 中 | 1m | 大 | 重 | 丈夫で壊れにくい |
| バール | 打撃 | 中 | 高 | 1m | 大 | 重 | 扉や窓もこじ開けられる |
| ゴルフクラブ | 打撃 | 中 | 中 | 1.2m | 中 | 軽 | 曲がりやすい |
| 物干し竿の槍 | 刃物 | 低 | 中 | 2m | 小 | 中 | つかまれにくい。狭い廊下では使えない |
| 消火器 | 道具 | — | — | 3m | 大 | 重 | 噴射で数秒の目くらまし。中身は1回きり |

- **傷み**：武器は使うたびに傷み、0になると折れる。「武器の状態」は状況欄に言葉で出す（新品・傷あり・ひびが入っている）。
- **改造**（木材・部品を使う）：
  - バット＋釘 → 頭への効き↑・傷みやすい
  - パイプの先を削る → 突きが使える
  - 竿＋包丁 → 槍
  - 武器にテープを巻く → 滑りにくい（命中↑）
- **見つかる場所**：金物店（バール・パイプ）、近所の空き家（バット・ゴルフクラブ）、家の台所（包丁）、ビルの廊下（消火器）、ベランダ（物干し竿）。

## 6. 狙う部位と結果

### ゾンビ側

| 部位 | 当てやすさ | 当たった時 |
|---|---|---|
| 頭 | 難しい | 武器の「頭への効き」で一撃か、傷が積み重なって倒れる |
| 脚 | 当てやすい | 倒れる（downed）→ 這って近づく（crawling）。速さが半分以下に |
| 腕 | ふつう | つかみかかる力が落ちる |
| 胴 | 一番当てやすい | ほとんど効かない。押し返して距離をとるのには使える |

- **倒れた相手の頭は狙いやすい**（＋大）。「脚を払う → 倒れたら頭」の段取りが自然に生まれる。
- **扉や柵に挟まった相手（pinned）**も頭を狙いやすい。
- ヘルメットをかぶった相手（armored）は打撃で頭を狙いにくい。刃物で目元や首を狙うか、脚から崩す。

### 成功の決まり方

```
基本値（部位ごと）
+ スキル × 0.4
+ 武器の命中 / 部位への補正
+ 相手の状態（倒れている +30、挟まっている +25）
− 暗さ（夜・停電 −15）
− 疲れ（休息状態に応じて最大 −20）
− 怪我（利き手の怪我 −15）
− 心の動揺（いまの nerve_penalty）
− 近くの数（2体目以降 1体ごとに −8）
→ 5〜95% に収める
```

数字は画面に出さない。**言葉で目安を出す**。

| 確率 | 言葉 |
|---|---|
| 〜20% | まだ難しい |
| 21〜45% | 当たるかもしれない |
| 46〜70% | 狙える |
| 71%〜 | 落ち着けば外さない |

スキルが上がると、同じ相手でも言葉が変わっていく。それが成長の手応えになる。

### プレイヤー側の怪我

つかまれた時、噛まれた時は**場所**を決める。

| 場所 | 噛まれた時 | 引っかかれた・打った時 |
|---|---|---|
| 腕 | 上着の厚さで防げることがある | 利き手なら命中が下がる（数日） |
| 手 | 防げない | 武器が握りにくい（数日） |
| 脚 | ズボン・ブーツで少し防げる | 移動が遅くなる・逃げにくい（数日） |
| 首・顔 | 助からない | — |

- **噛まれたら感染して死ぬ**。ここは崩さない。
- 腕を噛まれた時だけ、「その場で腕を切り落とせば、助かるかもしれない」という重い選択肢を検討する（後回し・要相談）。

## 7. 防具（服装）

服が噛みつきを防ぐ。物資探しの目的になる。

| 装備 | 守る場所 | 防ぐ割合 | 欠点 |
|---|---|---|---|
| 厚手のコート | 腕・胴 | 30% | 暑い季節は疲れやすい |
| 革ジャン | 腕・胴 | 50% | 珍しい |
| 雑誌を巻いた腕 | 腕 | 40% | ガムテープ・雑誌が必要。音を立てて作る |
| 作業用ブーツ | 脚 | 40% | — |
| ヘルメット | 頭 | 打撃・落下を防ぐ（噛みつきには関係ない） | 視界が少し狭い |

いまの `protection`（％）を、場所ごとの値に置き換える。

## 8. 地形と作戦

文章入力で一番面白くなるところ。場所ごとに「使える物」と「できること」を持たせる。

| 地形 | できること |
|---|---|
| 玄関・扉 | 扉で挟む（pinned）、扉越しに刺す、閉めて時間を稼ぐ |
| 狭い廊下 | 1体ずつしか来ない（同時に相手にするのは1体）。長い武器は振れない |
| 階段 | 上から叩くと命中↑・頭↑。下りてくる相手は転びやすい |
| 柵・フェンス | 柵越しに突く（つかまれない）。槍が活きる |
| 店の中 | 棚を倒して道をふさぐ、商品を投げる |
| 通り | 車の防犯ブザーでおびき寄せる、路地へ逃げ込む |

- 入力を「行動・狙う部位・使う物」に読み替えるのは、まずルール（言葉の一覧）で行い、読めない時だけAIに任せる。
- **勝ち負けはAIに決めさせない**。AIが返すのは `{action, target, weapon, object}` だけで、結果はルールとサイコロで決める（会話と同じ方式）。
- 地形でできない行動は、理由と一緒に断る（例：「廊下が狭くて、竿を振りかぶれない」）。

## 9. 音と群れ

- 打撃武器・物を倒す・叫ぶは大きな音を出す（`noise` が増える）。
- 音が一定を超えると、その場所の残り（`count`）から1体ずつ近づいてくる。戦いが長引くほど不利になる。
- 包丁・槍・素手で静かに倒すと、次が来にくい。

### 家での籠城戦（群れを迎え撃つ）

ゾンビゲームで一番盛り上がる場面として作る。
- 群れが家の前に来た時、補強した玄関（`door_hp`・`barricade`）が最初の壁になる。
- 扉が持ちこたえている間は、扉越しに刺す・二階の窓から物を落とす・裏口から逃げる、を選べる。
- 扉が破られたら廊下で1体ずつ迎え撃つ（狭い廊下の効果）。
- 同居人がいれば、扉を押さえる役、刺す役、明かりを持つ役に分かれる（同居人のスキル・役割が効く）。
- 準備が整っていれば10体前後は退けられる。準備がなければ逃げるしかない。

## 10. 戦うことのご褒美

| 戦った結果 | ご褒美 |
|---|---|
| 店や家の中を片付けた | その場所の物資を安全に探せる（探索の危険がなくなる） |
| 通りのゾンビを減らした | その地区が数日安全になる（`walkers.places` が減る） |
| 生存者を助けた | 信頼が大きく上がる・仲間になりやすい |
| 避難所の防衛を手伝った | 避難所が長く続く |
| 倒した相手が持っていた物 | ときどき武器・防具・鍵が手に入る |

戦えば得をするが、音・疲れ・武器の傷み・怪我という代償を必ず払う。

---

## 11. 記録と結末

- 倒した数、使い込んだ武器、一番危なかった怪我を `s.combat` に残す。
- `Chronicle` に転機を書く：初めて倒した日、初めて頭を一撃で割った日、群れを退けた夜。
- 結末（`epilogue.gd`）に反映する：
  - 「最初は包丁を握る手が震えていた。最後の冬には、鉄パイプ一本で家を守っていた。」
  - 「この街で、47体を土に還した。」
  - 戦わずに生き延びた人には「一度も、誰も傷つけずに生きた」。
