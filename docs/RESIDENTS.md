# 住人の仕組み（v149.38）

町の住宅地にある790世帯（団地300、北の住宅街150、駅前のマンション120、南の住宅街120、住宅街100）に、それぞれ家族がいる。どの家族も自分の状態と町の様子を見て毎朝行動を決める。プレイヤーが見ていてもいなくても、同じように進む。同じ seed からは同じ町の歴史になる。

## ファイル

| ファイル | 役割 |
|---|---|
| `scripts/residents.gd` | 世帯の本体。家族・性格・備蓄（seed から計算）、毎朝の判断、外出、感染、飢え、死、ドアでのやりとり、通りの気配と跡 |
| `scripts/communities.gd` | 第3段階。近所でまとまって暮らす集まり（蓄え・鍋・畑・雨水・バリケード・見張り） |
| `scripts/gangs.gd` | 第4段階。略奪者の集団（ねぐら、孤立した家や集まりへの襲撃、プレイヤーの家に来る者） |
| `scripts/wanderers.gd` | 第5段階。家を失って町に残り、生存者（survivors.gd）として毎時間動く人 |
| `scripts/shelter.gd` | 第2段階。避難所の人数は、町の世帯と外から来た人の合計 |
| `qa/residents_watch.gd` | 町を放っておいたときの観察（`DCJ_SEED`、`DCJ_DAYS`） |
| `tests/test_residents149_38.gd` | 第1〜6段階のテスト |

## 保存されるもの

`s.residents` に保存する。
- `hh`: エリアごとの世帯の行。中身は `[path, food, water, alive, bitten, turned, hungry, flags, since, dry]`。家族構成と性格は seed から毎回計算するので保存しない。
- `cm`: コミュニティ。
- `gangs`: 略奪者の集団。
- `player_cm`: プレイヤーが加わっているコミュニティ。
- `out` と `gang_out`: その日の外出と、略奪者の姿が見える時間帯。
- `raided`: エリアごとに、最後に襲われた日。
- `beyond`: 隣町に残っている食料（町の全員で共有）。

200日でおよそ35KB。計算時間は1日あたり約0.16秒（町全体を含む）。

## 世帯のたどる道（path）

| path | 意味 |
|---|---|
| `home` | 普段の暮らし |
| `holed` | 籠城。コミュニティの一員なら flag 256 |
| `shelter` | 避難所にいる |
| `away` | 町の外の親戚へ（警戒期に多い） |
| `gone` | 町を出た |
| `dead` | 全員亡くなった（家で亡くなった場合は flag 64、遺体がある） |
| `turned` | 家で発症した（閉じ込められていれば flag 32。いずれ外へ出て町の感染者になる） |
| `looter` | 略奪者の集団にいる |
| `wander` | 町をさまよっている（生存者 `res_<エリア>_<番号>` として） |

## 段階ごとの流れ

1. **住人:** 通常期は普段どおり。警戒期は買いだめでスーパーとコンビニの棚が減り、一部は町を出る。混乱期以降は避難所か籠城を選ぶ。籠城中は食事を減らし、足りなくなると空き家、店、隣町へ探しに出る。外の感染者の数しだいで噛まれる。噛まれたことを隠した人は翌朝発症し、家族も巻き込まれる。飢え・渇き・持病で亡くなるか、町を出る。
2. **避難所:** 町の世帯と外から来た人の合計で数える。満員になると教室も開放（定員280人）。人が出ていくときは世帯ごとに決める。夜に運び出される人は誰かの家族。陥落すると半数以上が犠牲になる。プレイヤーは「話を聞く」で町のうわさを聞ける。
3. **コミュニティ:** 崩壊後、棟・階層・一角ごとにまとめ役のもとで集まる。食料を一つにまとめ、畑・雨水・バリケード・見張りを持ち、物資探しには2人で出る。食料が足りなければ何世帯かが抜け、養える人数まで小さくなる。
4. **略奪者:** 飢えていて、思いやりが薄いか奪われた経験のある家が加わる。倉庫街・ホームセンター・ガソリンスタンド・交番のどれかをねぐらにする。孤立した家を襲い、強いときや飢えているときはバリケードの集まりも襲う。プレイヤーの家の明かりを見て来るのもこの集団。奪うものが無くなると町を出る。
5. **放浪者:** 家を失った人の一部が町に残り、生存者として毎時間動く。同時に10人まで。
6. **跡とうわさ:**
   - 跡: 内側からドアを叩く音、においのする部屋、荒らされた通り、留守を知らせる貼り紙。
   - うわさの経路: ラジオとSNS（襲撃や集団のこと）、避難所の話、町の放浪者（自分の元の通りのこと）、窓。
   - 同じうわさは1日1回まで。
