# アイテムのアイコン プロンプト集（v149.39）

持ち物欄に出るアイコン。今あるアイコン（濃紺の背景に品物だけの商品写真）とそろえる。
**保存先は `assets/items/<ファイル名>.jpg`。** 1024×1024 で作れば、こちらで 256×256 に縮める。置くだけで持ち物欄に出る。

優先度 **A**（よく見つかる・行動でよく使う）から作るのがおすすめ。下のコードブロックは、共通条件込みでそのまま貼れる。

全 205 種のうち、新しく作るアイコンは **188 枚**（A：66 枚、B：122 枚）。既にある16枚はそのまま使う。
