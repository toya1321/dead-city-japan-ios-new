## ねらい
「書いたことが、持っている物で筋が通っていれば、できる」ようにする。
行動を一つずつ作るのではなく、**アイテムに性質を持たせ、行動（動詞）がその性質を要求する**形にする。
新しいアイテムを足しても、性質さえ付ければ、今ある行動ですぐ使える。

例：
- 「ロウソクに火をつける」→ 動詞「点ける」は〈着火具〉と〈燃える・明かり〉を要求 → ライターとロウソクがあればできる。停電中の明かりになる。
- 「ガムテープで窓を補強する」→ 動詞「補強する」は〈貼れる〉か〈板〉を要求 → ガムテープで窓が少し強くなる（板より弱い）。
- 「空き缶を吊るして鳴子にする」→ 動詞「作る」の組み合わせ（〈音が鳴る〉＋〈紐〉）→ 鳴子。夜に誰かが近づくと音で気づける。
- 「シーツでSOSを書く」→ 〈大きな布〉があればSOSを作れる（今の救助の合図につながる）。

## 行動の決まり方
1. 入力を **動詞＋使う物＋相手（場所・人・物）** に分ける。
2. 動詞は決まった一覧（約25語）から選ぶ：
   食べる・飲む・点ける・消す・燃やす・照らす・温める・沸かす・切る・裂く・縛る・吊るす・貼る・ふさぐ・補強する・直す・作る・手当てする・投げる・鳴らす・書く・汲む・ためる・渡す・交換する・読む・遊ぶ
3. 動詞ごとに「要る性質」と「起きること」を決めておく。
   持ち物の中から、その性質を持つ物をゲームが探す。
   - 書いた物がその性質を持っていれば、それを使う。
   - 書いていなくても、持ち物に合う物があれば使う（「火をつける」→ ライターを使う）。
   - 合う物がなければ、理由を返す（「火をつける物がない。ライターかマッチが要る」）。
4. 起きることは、今あるゲームの仕組みにつなぐ。
   - 明かり → 停電中の明かり（外への光漏れも）
   - ふさぐ・補強 → バリケードの強さ
   - 鳴子 → 夜の襲撃に早く気づく
   - 暖 → 寒さの仕組み
   - SOS → 救助の合図
   - 手当て → 傷の回復
   - 投げる・鳴らす → 囮

## AIの役目（読み取りだけ）
AIには、次の3つを**一覧から選ばせるだけ**にする。
- 動詞（約25語の一覧から）
- 使う物（いま持っている物の一覧から）
- 相手（いる場所の部屋・物・人の一覧から）

できるかどうか、何分かかるか、何が起きるかは、**すべてゲームの決まりで決める**。
AIが選んだ物を持っていなければ、ゲームが断る（AIの思い込みでは何も起きない）。

AIを使わないときは、アイテム名・言い換えと動詞の辞書で読む。
