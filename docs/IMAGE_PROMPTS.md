# 画像素材の作り方（ChatGPT 画像生成用）

全部で約95枚。上から順に作るのがおすすめ。プロンプトはそのまま貼れるように書いてある。

---

## 共通のルール

### 場所の写真（A・B・C）
- **横長**（3:2 か 16:9）。ChatGPT の「横長」でよい。
- **写真そのもの**に見えること。イラスト・CG・絵画風にしない。
- **文字を入れない**（看板の文字・ロゴ・透かし・字幕なし）。読めない程度の看板はよい。
- 曇りの日中、自然光。人物は入れない（外の写真は人がいない方が状況に合う）。
- 場所は東京の住宅地（世田谷・渋谷あたりの静かな街）。

### 4段階の作り方（いちばん大事）
同じ場所の4枚は**同じ構図・同じアングル**にする。ゲームは時間の経過で写真を差し替えるので、構図が変わると別の場所に見える。

1. まず「平常」を作る。
2. 次に**その画像を添付して**、こう頼む：
   > この画像と**まったく同じ構図・同じカメラ位置・同じ建物**のまま、〔段階の説明〕に変えてください。写真のリアルさはそのまま、文字は入れないでください。
3. 「警戒」「崩壊」「荒廃」を、それぞれ平常の画像から作る（前の段階から作り続けると構図がずれやすい）。

段階の意味（ゲーム内の時期）：
| 段階 | ファイル名の末尾 | 時期 |
|---|---|---|
| 平常 | なし | 何も起きていない日常 |
| 警戒 | `_alert` | 感染が広がり始め、人々が備えている。まだ街は保たれている |
| 崩壊 | `_collapse` | 社会が崩れた後。荒らされ、放置され、汚れている |
| 荒廃 | `_overgrown` | 1年以上たった。草木に覆われ、風雨で傷んでいる |

### 顔（D・E）
- **正方形**、胸から上、**正面か少し斜め**、カメラ目線。
- 写真（ポートレート写真）。イラスト・アニメ風にしない。
- 背景は**無地の暗い青灰色**（ゲームの画面が濃紺なのでなじむ）。
- 表情は**落ち着いた自然な顔**（笑いすぎない・怖がらない）。ゲームの最初から最後まで同じ顔を使うので、汚れや血・けがは無し。
- 日本人。服は普段着か、職業が分かる程度の服（名札の文字は無し）。
- 1枚に1人。

### アイテム（F）
- **正方形**、**背景は透明**（透明が難しければ無地の白）。
- 写真のような質感、斜め上から見た角度、柔らかい影。
- 物が画面の7割くらいの大きさで、真ん中に1つ（または1まとまり）。
- **商品名・ロゴ・読める文字は入れない**（実在の商品に見えないように）。

## A. 避難所（小学校）4枚 ★最優先
ファイル名：`school.jpg`／`school_alert.jpg`／`school_collapse.jpg`／`school_overgrown.jpg`

**平常（school）**
> 東京の住宅地にある公立小学校の写真。校門の前から、門越しに校庭と3〜4階建ての白っぽい鉄筋コンクリートの校舎、横に体育館が見える構図。門は閉まっていて、周りは低いフェンスと植え込み。曇りの日中、自然光、人はいない。リアルな写真、横長、文字は入れない。

**警戒（school_alert）**（平常の画像を添付して）
> この画像と全く同じ構図のまま、避難所として使われ始めた様子に変えてください。校門は開いていて、門の前に白いテントと長机の受付、段ボール箱と水のペットボトルのケースが積まれている。体育館の入口に毛布の束。仮設の照明。人はいない。

**崩壊（school_collapse）**（平常の画像を添付して）
> この画像と全く同じ構図のまま、避難所が感染者に襲われた後の様子に変えてください。校門は倒れて歪み、テントは潰れ、段ボールや毛布が散乱している。体育館の窓ガラスが割れ、校舎の壁が汚れている。人はいない。

**荒廃（school_overgrown）**（平常の画像を添付して）
> この画像と全く同じ構図のまま、1年以上放置された様子に変えてください。校庭は背の高い雑草に覆われ、壁にツタが絡み、門は錆びて倒れたまま。窓は割れ、色あせている。人はいない。

## B. 家の中 15枚
今ある平常の写真（寝室・居間・台所・廊下・玄関）に、3段階を足す。**平常の画像はこちらから送る**ので、それを添付して作る（必要なら言ってください）。

家の中の段階は「街の様子」ではなく「**暮らしの変化**」：
| 段階 | 家の中の変化 |
|---|---|
| 警戒 | 備えている。水のペットボトルや缶詰が積まれ、カーテンは閉め気味。部屋はまだ片付いている |
| 崩壊 | 停電した籠城の暮らし。窓に段ボールや板、ろうそくやランタンの明かり、物が増えて散らかっている。薄暗い |
| 荒廃 | 1年以上の籠城。家具はすり減り、壁にしみ、手作りの道具や干した服、窓は板でふさがれたまま。暗く、物が少ない |

ファイル名（各3枚）：
- 寝室 `bedroom_alert.jpg`・`bedroom_collapse.jpg`・`bedroom_overgrown.jpg`
- 居間 `living_…`
- 台所 `kitchen_…`
- 廊下 `hall_…`
- 玄関 `entrance_…`

頼み方（例：寝室の崩壊）：
> この画像と全く同じ構図・同じ部屋のまま、停電した中で何週間も籠城している様子に変えてください。窓は段ボールと板でふさがれ、部屋はランタンとろうそくの明かりだけで薄暗い。床に水のペットボトルや缶詰、毛布が置かれ、少し散らかっている。人はいない。リアルな写真、文字なし。

部屋ごとの足すとよい物：
- 寝室：枕元に懐中電灯、重ねた毛布、着替えの山
- 居間：ラジオ、カセットコンロ、地図や紙のメモ（文字は読めない程度）、家具を寄せたバリケード
- 台所：空き缶、ポリタンク、カセットボンベ、使い終わった鍋
- 廊下：積んだ箱、立てかけた板や工具
- 玄関：板で補強した扉、家具のバリケード、立てかけたバール

## C. 建物まわり 12枚
平常の写真（集合住宅の外観・共用廊下・家の前・近所の空き家）に3段階を足す。**街の段階の説明（上の表）どおり**。平常の画像はこちらから送る。

ファイル名：
- 集合住宅の外観 `apartment_alert.jpg`・`apartment_collapse.jpg`・`apartment_overgrown.jpg`
- 共用廊下 `corridor_…`
- 家の前 `building_…`
- 近所の空き家 `vacant_house_…`

頼み方（例：警戒）：
> この画像と全く同じ構図のまま、感染症が広がり始めた街の様子に変えてください。ゴミ袋が少したまり、窓のカーテンは閉じられ、玄関先に注意を呼びかける紙（文字は読めない程度）。まだ荒れてはいない。人はいない。

崩壊：
> …社会が崩れた後の様子に。ゴミが散乱し、窓ガラスが割れ、ドアが開いたまま、壁に汚れ、放置された自転車。人はいない。

荒廃：
> …1年以上放置された様子に。雑草とツタに覆われ、錆びて色あせ、雨のしみ。人はいない。

## D. 顔：だれにでも使う顔 10枚 ★同居人に使う
ファイル名：`person_<f|m>_<年代>.jpg`（f=女性、m=男性）

共通のプロンプト（〔 〕を入れ替える）：
> 日本人の〔年代〕の〔女性／男性〕の、胸から上のポートレート写真。正面を向いてカメラを見ている、落ち着いた自然な表情。〔服装〕。背景は無地の暗い青灰色。柔らかい自然光。リアルな写真、正方形、文字なし。

| ファイル名 | 年代 | 服装の例 |
|---|---|---|
| `person_f_child.jpg` | 8〜10歳の女の子 | トレーナー |
| `person_m_child.jpg` | 8〜10歳の男の子 | パーカー |
| `person_f_teen.jpg` | 16〜18歳の女性 | カーディガン |
| `person_m_teen.jpg` | 16〜18歳の男性 | パーカー |
| `person_f_young.jpg` ★ | 20代後半の女性 | ニットのセーター |
| `person_m_young.jpg` ★ | 20代後半の男性 | 無地のシャツ |
| `person_f_middle.jpg` | 40代後半の女性 | ブラウスにカーディガン |
| `person_m_middle.jpg` | 40代後半の男性 | ポロシャツ |
| `person_f_senior.jpg` | 70歳前後の女性 | 落ち着いた色のニット |
| `person_m_senior.jpg` | 70歳前後の男性 | ジャケット |

★の2枚が最優先（同居人の多くはこの年代）。同じ年代でもう1人分の顔が欲しい時は `_2`（例 `person_f_young_2.jpg`）で、顔立ち・髪型を変えて作る。

## F. アイテム 15枚
ファイル名：`<名前>.png`（透明背景の png）

共通のプロンプト：
> 〔物〕の写真。斜め上から見た角度で、画面の中央に置く。背景は透明（できなければ無地の白）、柔らかい影。商品名・ロゴ・読める文字は入れない。リアルな写真の質感、正方形。

## 渡し方
できた画像はこのチャットに貼ってください。ファイル名を書いてもらえると早いですが、無くても中身を見て名前を付けます。何枚ずつでも大丈夫です。
