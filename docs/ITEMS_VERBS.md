# 行動（動詞）と決まり 設計案（手順3）

## 判定の流れ
1. 入力を **動詞＋使う物＋相手** に分ける（AIは一覧から選ぶだけ。AIがないときは辞書）。
2. 動詞ごとの「要る性質」を、**書いた物 → 手元（リュック）→ 家の備蓄** の順に探す。
   - 書いた物がその性質を持たないときは、理由を返して何もしない（「新聞紙では窓は補強できない。板かテープが要る」）。
   - 書いていなければ、持っている物から一番合う物を選ぶ（「火をつける」→ ライター、なければマッチ、晴れていれば虫眼鏡）。
3. 物の**質**で結果が変わる（板＋釘＞段ボール＋テープ。懐中電灯＞ロウソク＞ケミカルライト）。
4. かかる時間、減る物（ロウソクは燃え尽きる、テープは使い切る）、**周りへの影響**（明かりや煙・音は、感染者や略奪者に気づかれやすくなる）を決まりで決める。

## 進め方（2回に分ける）
- **第1弾（12）**：今の仕組みにすぐつながる、生き延びるための基本。
  食べる、飲む、手当てする、薬を飲む、暖を取る／着る、火をつける／消す、沸かす、ろ過する、補強する／ふさぐ、目張りする、仕掛ける、投げる／鳴らす／合図を送る
- **第2弾**：作る、直す、切る・裂く、縛る、書く、こじ開ける、照らす、焚き火、汲む、釣る・採る、抜き取る、充電する、植える・掘る、運ぶ、気晴らし

## 食べ物の扱い（決まったこと）
- **腐る・傷む仕組みは入れない。** 現実的ではないが、管理の手間が大きすぎるため。卵も冷凍食品も、いつまでも食べられる。
- 「食料○人日」は「保存食のまとめ」として残し、缶詰・米・カップ麺などは品物として別に持つ。品物にはそれぞれ「何人日分か」を決め、合計を食料として数える（家族の食事、集まり、配給などの今の仕組みはそのまま動く）。
- 食べるときは、書いた品から。書かなければ、加熱の要らない物から。

## 明かり・煙・音
- 今の「明かりがついていると外から見える」の決まりを広げる。火・煙・におい・大きな音も、窓をふさいでいなければ（音は家の中でも）感染者や略奪者に気づかれやすくなる。
