# v149.35 の画像

v149.35 で増えた・差し替えた画像（町の写真、家の中、住人の顔、暮らしの場面、行動写真など161枚）を、ゲーム内と同じパスで置いている。

`ci/v149.35-world.patch` にはコードと文章（`.import` を含む）だけが入っていて、画像は入っていない。パッチに画像を入れると GitHub の上限に近づくため、分けている。

ビルドでは、パッチを順に当てた後にこのフォルダの中身を上書きでコピーする。

```
git apply --directory=game ci/v149.34-shop.patch
git apply --directory=game ci/v149.35-world.patch
cp -R ci/v149.35-assets/assets/. game/assets/
```

パッチを当ててからこのフォルダをコピーした結果が、開発中の作業ツリーと一致することを確かめてある。

これ以降の版でも画像は同じやり方にし、`ci/v149.NN-assets/` に置く。
